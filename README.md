# Arunika Crumbs & Brew

Website resmi kafe dan bakery Arunika yang menyajikan menu makanan, minuman, promo, serta informasi pemesanan dengan tampilan modern dan responsif.

## Tentang Website

Arunika Crumbs & Brew dibuat untuk memperkenalkan menu andalan kafe, memudahkan pelanggan melihat pilihan produk, dan memberikan pengalaman pemesanan yang sederhana.

## Fitur

- Tampilan modern dan responsif
- Daftar menu makanan dan minuman
- Detail produk dan harga
- Informasi promo
- Informasi lokasi dan jam operasional
- Kontak dan pemesanan
