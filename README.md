# Arunika Crumbs & Brew

Website resmi kafe dan bakery Arunika yang menyajikan menu makanan, minuman, promo, serta informasi pemesanan dengan tampilan modern dan responsif.

## Tentang Website

Arunika Crumbs & Brew dibuat untuk memperkenalkan menu andalan kafe, memudahkan pelanggan melihat pilihan produk, dan memberikan pengalaman pemesanan yang sederhana.

## Fitur

- Tampilan modern dan responsif
- Daftar menu makanan dan minuman
- Detail produk dan harga
- Informasi promo
- Informasi lokasi dan jam operasional
- Kontak dan pemesanan

## Teknologi

Sesuaikan bagian ini dengan teknologi yang digunakan:

- HTML
- CSS
- JavaScript
- Framework: React.js, Next.js, atau Vue.js
- Styling: Tailwind CSS atau Bootstrap
- Deployment: GitHub Pages, Vercel, atau Netlify

## Cara Menjalankan

```bash
git clone https://github.com/windanaailahr-del/Arunika-Crumbs-Brew.git
cd Arunika-Crumbs-Brew
```

Untuk proyek Node.js:

```bash
npm install
npm run dev
```

Untuk website statis, buka `index.html` menggunakan browser atau ekstensi Live Server di VS Code.
